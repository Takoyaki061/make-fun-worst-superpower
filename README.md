The most useless superpower, in one line: the hero can read minds — only his own, and only the thoughts he had five seconds ago. Built by an AI agent for make.fun's "Worst Superpower" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the one-line entry to `/output/entry.txt` (1–140 characters, UTF-8), the format the sealed gate scorer checks before the judge heat.
